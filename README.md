# Python Expense Tracker

A simple CLI tool built with Python to track daily expenses in Ksh. I built this to practice file handling and JSON.

## Features
- Add expense with amount, category and note
- View all expenses with total spent
- Data saved locally in expenses.json

## How to Run
python main.py

## What I Learned
- How to read/write JSON files in Python
- Handling user input and validation
- Using datetime module
